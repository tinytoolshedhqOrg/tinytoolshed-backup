# 亞洲小編工作流程

1. 依[分工表](../../marketing/social/regions.md)，處理日本、南韓、台灣、泰國、越南在 X、Threads、Instagram 的內容。
2. 先確認產品資料及當地 App Store 上架狀態，再閱讀相關討論與各國用語庫。
3. 依當地語言撰寫專屬貼文、回覆或短影音腳本；挑選與產品用途相關的討論，不用罐頭回覆。
4. 每則貼文、留言與回覆都先交 Chun 核准。素材、產品聲明及發布條件遵守[社群執行規則](../../marketing/tiny-toolshed-launch.md)。
5. 記錄發布網址、平台、國家、台北時間與成效，避免重複回覆。
6. 每週一在上述三個平台學習各國內容並更新用語庫，每週彙整成效。
7. 帳號、登入或憑證問題交由黑嘛嘛或蘋果大師處理，不將憑證寫入 repo。
